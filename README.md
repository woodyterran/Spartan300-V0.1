# Spartan300 V0.1

Spartan300-V1 的简易采集版：面向专家高技能手工劳动视频采集，用于机器人训练。沿用 V1 的 DeepReach 品牌、米白底色（#fffaf3）、陶土橙（#bd4f24）、深棕文字（#302b26）和绿色收益状态；直接复用 V1 的专家及手艺配图。Mac 本地移动端 H5 交互原型，无第三方依赖。需要 Node.js 20 或以上版本。

## 启动

首次从 GitHub 获取代码：

```sh
git clone https://github.com/woodyterran/Spartan300-V0.1.git
cd Spartan300-V0.1
npm run dev
```

本项目无第三方运行依赖，不需要安装额外 npm 包。本机已有项目时也可直接启动：

```sh
cd /Users/wanlong/Documents/ChatGPT/Spartan300-V0.1
npm run dev
```

服务器监听 `0.0.0.0:3000`，启动时通过 macOS `networksetup` 找到 Wi-Fi 网卡，再用 `ipconfig getifaddr` 查询真实 IPv4。终端打印 Local 与 Wi-Fi URL；无法确认 Wi-Fi 时会标明为未验证网络地址，不虚构地址。端口占用时报告错误，不停止其他进程。

手机与 Mac 连接同一 Wi-Fi，用终端打印的 Wi-Fi URL 访问。Mac 保持运行且服务器不退出。如果访问失败，检查 macOS 是否允许 Node 的入站连接、是否使用访客网络，以及路由器是否启用设备隔离。无需连接任何云服务。

- `/`：自动适配手机和桌面。
- `/preview.html`：桌面查看 390px 宽度、自适应高度的手机尺寸预览。
- `/admin`：配套 PC 结算管理后台。
- `/api/health`：只读服务状态与当前 Wi-Fi 地址。

## 完整流程

1. 登录，直接输入想展示的具体高技能手艺。
2. 按顾问提示补充工作场景、专业操作工具和拍摄设备，完成三轮模拟对话。
3. 模拟评估通过后出现拍摄指导和一次授权。普通风景内容不符合采集方向；重复手艺、隐私、安全或缺少录音条件的预设关键词会演示拒绝；不是实际内容审核。
4. 进入准备页，选择模拟或真实设备录制。确认横屏与声音要求，点击圆形按钮开始。
5. 开始即消耗授权；录制中不可切换摄像头。结束、中断或刷新后均不能复用该授权。
6. 模拟拍摄可切换“模拟断网 / 恢复网络”，结束后查看模拟缓存、补传与审核状态。模拟上传成功后显示“请等待审核结果”，不提供用户自行审核或计入收益的入口；收益页面保留预置的演示余额。
7. “我的”中可申请全额演示结算，申请会进入本机 PC 后台；管理员处理前可撤销恢复余额。后台可登记线下付款结果或填写原因退回。处理状态和备注同步到手机端，不会通知外部联系人或发起真实付款。

## 真实实现与模拟边界

| 能力 | 实现 |
| --- | --- |
| 手机号密码登录 / 注册 | 本机服务器认证、加盐密码摘要与 HttpOnly 会话，无短信或真实身份校验 |
| AI 咨询 / 悬赏评估 / 拍摄指导 | 本地规则与预设文案，无 AI 或外部悬赏接口 |
| 语音入口 | 可编辑的模拟转写，无麦克风采集或语音识别 |
| 拍照 / 相册入口 | 原生图片选择器，咨询参考图片仅在本地，不识别、不上传；拒绝视频 |
| 单次拍摄授权 | 本地状态校验，开始时消耗，刷新后仍消耗；不是服务端安全授权 |
| 模拟拍摄 | 插画预览、计时与模拟分片，无实际视频数据 |
| 真实录制 | 仅在安全环境且设备支持时，使用 getUserMedia + MediaRecorder 采集摄像头与必需音轨 |
| 规格 | 真实模式要求横屏、实际视频轨 1920 × 1080，规格不满足或无音轨时阻止开始 |
| 摄像头切换 | 仅录制前支持前后偏好切换，实际设备选择由浏览器决定；录制中锁定 |
| 本地分片 | 真实模式以约 5 秒间隔写入 IndexedDB；间隔取决于浏览器，不保证精确 |
| 分片上传 / 断网补传 | 只有模拟状态，没有上传请求、对象存储、上传队列或服务端合并 |
| 回放 / 导出 | 真实本地分片组合为 Blob，提供播放器和下载；浏览器编码兼容性决定是否能播放 |
| 拍摄记录 / 收益 | 采集文件仍在浏览器本地，默认账户预置三条模拟样例；金额均为演示 |
| 结算与用户管理 | 本机 JSON 数据持久化；移动端提交申请、PC 后台处理与账户状态联动，没有支付渠道 |

局域网 **HTTP 的手机网页通常不属于安全环境，不能使用 getUserMedia**。同一 Wi-Fi URL 优先用于完整模拟交互测试。真实摄像头测试需使用 Mac 的 `http://localhost:3000` 或另行配置手机信任的 HTTPS；本项目没有安装证书或绕过浏览器安全限制。

真实录制最长 30 分钟，到时自动停止；切后台、音轨或设备中断会结束录制并保存已收到的分片。浏览器退出、锁屏、系统挂起、存储容量不足时，不能保证完整恢复；页面下次打开会把未完成录制标记为中断，授权不会恢复。请保持前台并及时导出。IndexedDB 可能被浏览器清理。没有生产级持久化、恢复协议或后台上传保证。

## PC 结算管理后台

电脑打开 `http://localhost:3000/admin`，或使用启动时打印的 Wi-Fi 地址后加 `/admin`。

- 管理员账号：`admin`
- 演示密码：`spartan300-admin`
- 可通过 `SPARTAN_ADMIN_PASSWORD` 环境变量替换默认管理员密码。
- 工作台总览：待结算金额、用户概况、近 7 日演示付款登记、最近操作。
- 结算申请：状态筛选、搜索、详情、导出 CSV；管理员确认后登记线下已付款，或填写原因退回。
- 用户管理：搜索、查看资料与余额、修改姓名/手艺/备注、新增演示用户、启用或停用账户、导出 CSV。
- 操作记录：申请、撤销、付款登记、退回和用户修改留痕。

手机端“我的”每约 5 秒刷新一次账户与结算状态，且在弹窗或录制时暂停刷新，避免打断操作。后台每约 15 秒静默刷新一次，编辑表单或查看详情时暂停；也可手动刷新。

全额申请在服务器原子预留余额，重复提交、重复登记和处理后的再次撤销均会被阻止。金额按整数分保存。处理前撤销或管理员退回只恢复一次余额；付款登记只更新记录，不调用银行、微信、支付宝或任何真实支付服务。

运行数据保存在 `.data/store.json`，采用临时文件写入后替换的方式保存，账户密码摘要不通过 API 返回；该目录不对网页开放且已忽略提交。会话保存在服务器内存，服务器重启后可能需要重新登录。请保留 `.data/` 以保留演示业务记录。此系统尚未包含生产级数据库、备份、完整权限体系或 HTTPS 部署。

旧版手机演示数据会在首次接入本机服务时导入一次；原浏览器数据在 `s300-before-server-<手机号>` 保留快照。相同手机号此前在多个浏览器产生的不同演示余额，以首次导入的数据为准，其余浏览器原快照保留；之后以服务器为准，客户端不能反复覆盖管理员处理结果。旧账号可能需要重新登录一次。视频文件不会迁移到服务器。

预置的其他师傅、联系电话、待结算记录与付款登记均为演示数据，没有自动联系任何人。移动端仍保留“模拟上传成功，等待审核”的流程，不会由用户自行点击审核通过计入收益。
